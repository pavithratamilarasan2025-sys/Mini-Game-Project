**🛍️ Retail Sales Analytics Project (Real-World Data Science)**



📌 Project Overview



This project performs \*\*end-to-end Retail Sales Data Analysis\*\* using Python.  

It transforms raw transactional data into meaningful business insights using data analytics techniques.



The goal is to understand sales trends, profitability patterns, and product performance across regions.







🎯 Objectives



\- Analyze retail sales performance across categories

\- Identify top-performing products and regions

\- Perform feature engineering for business insights

\- Understand profit distribution patterns

\- Visualize key business metrics

\- Develop real-world data analysis skills





📂 Dataset Information



The dataset contains retail transaction records including:



| Column | Description |

|--------|-------------|

| OrderID | Unique order ID |

| OrderDate | Date of purchase |

| CustomerID | Customer identifier |

| Product | Product name |

| Category | Product category |

| SubCategory | Product sub-category |

| Region | Sales region |

| Quantity | Units sold |

| UnitPrice | Price per unit |

| Discount | Discount applied |

| CostPrice | Product cost |

| Profit | Profit earned |







⚙️ Features Implemented



✔ Data loading \& exploration  

✔ Feature engineering (Sales \& Revenue calculation)  

✔ Category-wise analysis  

✔ Region-wise profit analysis  

✔ Top product performance analysis  

✔ Correlation analysis  

✔ Data visualization  







🛠️ Technologies Used



\- Python 🐍  

\- Pandas 📊  

\- Matplotlib 📈  

\- Seaborn 🔥  







📊 Visualizations Generated



\- Sales by Category (Bar Chart)  

\- Profit by Region (Pie Chart)  

\- Correlation Heatmap  







📈 Key Insights



\- Electronics generate the highest revenue  

\- South region contributes major profit share  

\- Certain products consistently outperform others  

\- Discounts directly impact net revenue  

\- Strong correlation between quantity and sales
